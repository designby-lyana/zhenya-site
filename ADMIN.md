# Адмінка сайту

Власна адмінка для Жені за адресою **`/admin`** (наприклад, https://zhenya-bychkova.r-kharuzina.workers.dev/admin).
Замінює Pages CMS.

## Як вона працює

```
Женя змінює щось в адмінці
   ↓ зміни одразу зберігаються в чернетку (сховище Cloudflare KV, спільне для телефона й комп’ютера)
   ↓ на сайті поки нічого не змінилось
Женя натискає «Опублікувати»
   ↓ адмінка робить один коміт у гілку main на GitHub
Cloudflare бачить коміт і перезбирає сайт (1–2 хв)
```

- **Чернетка** — одна на всіх. Її видно з будь-якого пристрою, де Женя увійшла.
- **«Скасувати всі зміни»** повертає все як на сайті й прибирає нові файли.
- **Фото** адмінка сама зменшує в браузері до 2560 px (~1 МБ). Легкі копії під різні екрани (WebP) сайт робить під час збірки, як і раніше.
- **Правки в коді** (через GitHub) не конфліктують з чернеткою: адмінка накладає зміни Жені поверх свіжого main, поле за полем.
- Історія всіх змін — це історія комітів на GitHub. Будь-яку версію можна повернути.

## Що де лежить

| Що | Де |
|---|---|
| Сервер адмінки (Cloudflare Worker) | `worker/index.js` — відповідає лише на `/api/*`, решту віддає як статичний сайт |
| Читання й запис у GitHub | `worker/github.js` |
| Як файли контенту стають «документом» адмінки і назад; злиття змін | `worker/content.js` |
| Вхід (пароль, cookie на 60 днів) | `worker/access.js` |
| Інтерфейс адмінки (React) | `src/admin/` — `App.jsx`, сторінки в `src/admin/pages/` |
| Сторінка `/admin` | `src/pages/admin/index.astro` |
| Список фото, які використовує сам код (їх не можна видалити в «Усіх файлах») | `src/pages/admin/code-media.json.js` |
| Вайбовий екран (35 плиток) | `src/data/vibe.json` (раніше був прямо в `index.astro`) |
| Налаштування Worker | `wrangler.jsonc` |

## Запуск (одноразово)

### 1. Токен GitHub — щоб адмінка могла записувати зміни
1. github.com → аватарка → **Settings** → **Developer settings** → **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Name: `zhenya-admin`. Expiration: найдовший доступний строк — і поставте собі нагадування в календар оновити токен.
3. **Repository access** → Only select repositories → `zhenya-site`.
4. **Permissions** → Repository permissions → **Contents: Read and write**.
5. Generate → скопіюйте токен (його покажуть один раз).

### 2. Секрети в Cloudflare
dash.cloudflare.com → **Workers & Pages** → `zhenya-bychkova` → **Settings** → **Variables and Secrets** → **Add**, тип **Secret**:

| Назва | Значення |
|---|---|
| `GITHUB_TOKEN` | токен з кроку 1 |
| `ADMIN_LOGINS` | `Женя:пароль-Жені;Ляна:ваш-пароль` — ім’я і пароль через двокрапку, людей — через крапку з комою |

Паролі — довгі, але прості для запам’ятовування (наприклад, три слова через дефіс). Щоб змінити пароль або закрити комусь доступ — просто відредагуйте `ADMIN_LOGINS`: старі входи одразу перестануть діяти.

### 3. Перевірити налаштування збірки
Там само → **Settings** → **Build**:
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

Сховище чернетки (KV) створиться само під час першого розгортання.

### 4. Злити гілку `admin` у `main`
Після злиття Cloudflare перезбере сайт. Відкрийте `/admin`, увійдіть своїм паролем і перевірте: змініть щось дрібне → «Опублікувати» → за 1–2 хв зміна на сайті.

### 5. Передати Жені
- Посилання на `/admin` і її пароль.
- На телефоні: відкрити посилання → «Поділитися» → «На екран „Додому“» — адмінка стане як застосунок.
- Pages CMS більше не потрібен: видаліть `.pages.yml` з репозиторію.

## Для розробки

```bash
npm install
npm run build
npx wrangler dev --var DEV_USER:Ляна --var GITHUB_TOKEN:...   # адмінка на http://localhost:8787/admin
```

`DEV_USER` вимикає перевірку пароля — лише для локальної роботи.
